# Идеи для будущих версий (после 1.0)

## 1. Фильтрация при поиске
- **По цене:** пользователь может задать диапазон (от xx до xxx). Реализация: фильтрация уже полученных результатов на стороне Django или передача параметра в парсер (если маркетплейс поддерживает).
- **По сроку доставки:** варианты: «менее 3 дней», «менее 5 дней», «менее 7 дней», «любой». Требует парсинга информации о доставке (сейчас не извлекается). Возможно, для каждого товара нужен отдельный запрос – сложно.
- **По маркетплейсу:** пользователь может выбрать на каких конкретно маркетплейсах ему искать товар.

## 2. Настройка количества результатов поиска
- Пользователь сам выбирает, сколько товаров выводить (от 10 до 30, шаг 5 или 10). Технически просто: добавить поле ввода на странице поиска и передавать параметр `limit` в парсер. Wildberries поддерживает `&limit=N`. Для Ozon – позже.

## 3. Сохранение изображений товаров
- Скачивать главное изображение товара из карточки поиска и сохранять в `media/`. Добавить поле `image` в модель `Product` или `Offer`. Требует:
  - Дополнительного запроса для скачивания (или извлечения ссылки и сохранения).
  - Обработки ошибок.
  - Увеличения дискового пространства.
- Полезно для визуального отображения в карточках товара.

## 4. Изменения в настройках
- Изменение темы всего сайта.
- Изменение валюты. Можно реализовать прямо в js.
