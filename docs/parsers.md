# Парсеры маркетплейсов

PriceHunter использует Selenium для получения данных с динамических страниц. Парсеры находятся в `core/utils/parsers.py`.

## Абстрактный класс `AbstractParser`

Определяет обязательные статические методы:

- `search_by_query(query, answer_cnt, price_limit, delivery_limit)` – поиск по запросу, возвращает список предложений.
- `search_by_url(url)` – получение данных по прямому URL.
- `update_by_url(driver, url)` – обновление цены, наличия, доставки (используется внутри пакетного обновления).
- `update_and_save_batch(urls)` – массовое обновление через один драйвер.

## Реализация `WbParser` (Wildberries)

### Настройка драйвера

Функция `get_driver()` создаёт экземпляр Chrome с опциями:

- Отключение автоматизации (`--disable-blink-features=AutomationControlled`).
- Подмена `navigator.webdriver`.
- Задание языка `ru-RU`.
- Headless-режим (по желанию).
- Случайный User-Agent через `fake_useragent`.
- Отключение уведомлений, сохранения паролей.

### Основные селекторы (по состоянию на май 2026)

|---------|--------------|

### Метод `search_by_query`

1. Открывает страницу поиска `https://www.wildberries.ru/catalog/0/search.aspx?search={query}`.
2. Ждёт загрузки, кликает сортировку «По возрастанию цены».
3. Применяет фильтр цены (если передан `price_limit`).
4. Пагинация: загружает карточки по 20 штук, скроллит.
5. Для каждой карточки:
   - Проверяет, не добавлен ли уже такой артикул в БД (чтобы не дублировать).
   - Извлекает название, цену, наличие, артикул, URL, доставку.
   - Добавляет в результат.
6. Возвращает список словарей с ключами: `name`, `price`, `availability`, `article_number`, `url`, `delivery_time`, `marketplace`.

### Метод `search_by_url`

- Открывает страницу товара.
- Обрабатывает 404 (блок `h1.content404__title`).
- Парсит название (`h2.productTitle--lfc4o`), цену (ищет в нескольких вариантах), наличие (наличие кнопки «В корзину»), артикул (`button.cellCopy--sPwsd > span`), доставку (`div.deliveryTitleWrapper--WMRNu > span`).

### Метод `update_by_url`

- Аналогичен `search_by_url`, но возвращает только изменяемые поля: `new_name`, `new_price`, `availability`, `new_delivery_time`.

### Метод `update_and_save_batch`

- Принимает множество URL.
- Создаёт один драйвер.
- Для каждого URL:
  - Вызывает `update_by_url`.
  - Если успешно – внутри транзакции:
    - Получает `Offer` через `select_for_update()`.
    - Если цена или наличие изменились – создаёт `PriceHistory`.
    - Обновляет поля `price`, `in_stock`, `title` (с очисткой через `clean_product_name`), `delivery_days`.
    - Сохраняет.
  - Логирует ошибки (`Offer.DoesNotExist`, парсинг).
- Возвращает множество обновлённых `Offer`.

## Обработка ошибок и логирование

- Используется `logging.error` для критических проблем.
- При ошибке парсинга одного URL – переход к следующему.
- В конце обязательно `driver.quit()`.

## Анти-блокировочные меры

- Случайный User-Agent.
- Отключение флага `navigator.webdriver`.
- Headless-режим (но он иногда детектится).
- Имитация действий человека (ожидания, скролл, клики через ActionChains).

## Расширение на другие маркетплейсы

Чтобы добавить Ozon или Яндекс.Маркет:

1. Создать класс `OzonParser`, унаследованный от `AbstractParser`.
2. Реализовать все статические методы.
3. Добавить slug и класс в словарь `PARSERS_BY_SLUG` в `views.py` и в кастомных командах.

Пример структуры для нового парсера – см. заглушки в текущем `parsers.py`.
